Detection Lab

A controlled demonstration for checking whether your antivirus detects the standard EICAR test pattern.

Safety note: This is not malware and does not exploit your device. The test pattern is designed for antivirus testing. Your security software may block or quarantine the downloaded test file.

Antivirus test file

Press the button to create the standard EICAR test file in your browser. It does not install anything, run a program, change settings, or contact a server.

If Bitdefender blocks the download or reports a detection, that demonstrates detection of the test file—not necessarily that it classifies this website's URL as malicious.

How to run the test

  1. Use a computer where Bitdefender is installed and active.
  2. Open this page from a local copy or trusted test host.
  3. Press Generate EICAR test file once.
  4. Observe Bitdefender's alert or quarantine action. Do not restore or whitelist the file.
  5. Delete any remaining test file and review the detection in Bitdefender.

What this test tells you

File detection: whether the antivirus recognizes the EICAR test pattern.

Website reputation: a separate URL-classification feature. This harmless page cannot guarantee that Bitdefender will label its address as malicious.

ThreatSite is an educational antivirus test page. It contains no real malware, credential collection, exploit, or persistence behavior.
